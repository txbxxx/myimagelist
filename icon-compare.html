③ 关于 🐰 兔子吉祥物

下面是 icon 库里的兔子——都偏简笔，撑不起"吉祥物"。建议：① 保留 emoji 🐰；② 用 OpenMoji 统一渲染；③ 定制手绘 SVG（最契合描边+硬阴影主题）。

④ 怎么在项目里用

功能图标（已装，直接用）：

<script setup>
import { Delete, EditPen, Download, UploadFilled } from '@element-plus/icons-vue'
</script>
<template>
  <el-icon><Delete/></el-icon>
</template>

情绪图标（彩色/duotone，引一个包吃下所有库，按需加载）：

pnpm --prefix client add @iconify/vue

<script setup>
import { Icon } from '@iconify/vue'
</script>
<template>
  <Icon icon="ph:heart-duotone" />
  <Icon icon="solar:rocket-bold-duotone" />
</template>
