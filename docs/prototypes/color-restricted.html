🎨 改后精简色板 4 色

  • 去掉所有 linear-gradient，按钮、头部、上传区全部用纯色。
  • 分类标签不再「一个分类一个色」，统一用白底描边，当前选中才变粉。
  • 背景图案也去掉四色散点，改用纯色奶油底。

📊 当前颜色统计

  • CSS 变量中定义了 11 种糖果色 + 3 种棕/白/墨。
  • 代码中实际出现约 30+ 个不同色值（含半透明、渐变插值）。
  • 按钮、头部、卡片、上传区、进度条、弹窗头部大量渐变。
  • 背景有 4 层径向渐变装饰点，视觉上最显「花」。

✅ 这样改的好处

  • 更干净：页面第一眼不会到处跳色，图片内容本身更突出。
  • 更高级：少色 + 粗描边反而更有「贴纸感」，不会廉价。
  • 更好维护：新增组件不用纠结配哪个糖果色。
  • 更易访问：颜色语义清晰：粉 = 主要操作/选中，棕 = 结构和文字。

⚠️ 需要注意

  • 分类管理里的色板选择器（8 色）可以保留——那是用户自定义分类颜色的功能，不是界面主色。
  • 状态色（成功/失败/警告提示）如果强制只剩 4 色，可能会降低辨识度，建议用图标 + 文案弥补。
  • 如果担心太单调，可在插画、空状态、emoji上保留多彩，界面本身保持克制。
