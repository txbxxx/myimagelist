圆直搭配 · 三级圆角体系

不全是圆角 · 内容直角 + 结构小圆角 + 交互胶囊

① 直角

border-radius: 0

图片 / 视频 / 弹窗外框。内容是主角，直角框住最严谨，主流图库照片几乎都直角。

② 小圆角

border-radius: 8px

卡片 / 面板 / 输入框。结构容器，规整不死板，承上启下。

③ 胶囊

border-radius: 999px

按钮 / chip / 头像。交互元素，圆暗示"可点"，亲和活泼。
