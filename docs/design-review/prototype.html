糖果图库 · 优化原型 v2

基于 design-review/report.md 的高/中优先级问题，逐项给出「改前 → 改后」对照。下方开关可全局模拟效果：

1. 减少动态效果支持

高优先级

报告问题：所有动画（float / pulse / spin-bounce）对前庭障碍用户不友好。修复：在 cartoon.css 增加 prefers-reduced-motion 媒体查询。点顶部「🐢 模拟减少动态效果」即可看到全场动画停止。

2. 键盘焦点可见 + 语义修复

高优先级

报告问题：焦点指示器被自定义阴影覆盖；登录页「切换注册」用的是无 href 的 <a>，键盘无法聚焦。修复：统一 :focus-visible 焦点环；链接式交互改用 <button>。点顶部「⌨️ 高亮焦点」然后按 Tab 浏览下面控件。

改后：全部可聚焦、焦点环清晰可见

💡 焦点环用双层阴影（底色 + 主题蓝），在奶油底和任何糖果色上都清晰；aria-label 让读屏器能念出图标按钮的用途。

3. 图片卡片：移动端操作可见

高优先级

报告问题：下载按钮只在 hover 时出现，手机用户永远看不到。修复：触控设备（@media (hover: none)）下操作按钮常显；桌面保持 hover 显示，同时支持 focus-within（键盘 Tab 到卡片时也显示）。点顶部「📱 模拟触控设备」对比。

4. 分类颜色对比度：文字色自动切换

高优先级

报告问题：#FDFFB6、#FFD6A5 等浅糖果底上深褐字对比度仅 3.5–3.8:1，不达 WCAG AA（4.5:1）。修复：保存分类时按背景亮度自动选择文字色（深褐 #2E2019 或白），并对极端浅色给出提示。下面是真实计算结果：

😊 改后：按亮度自动选文字色（均 ≥ 4.5:1）

💡 约 15 行工具函数：算相对亮度 → 与两个候选文字色分别求对比度 → 取较高者。同时给色板的每个色点加 aria-label="选择颜色 柠檬黄"。

5. 预览弹窗：关闭按钮 + 焦点圈禁

中优先级

报告问题：show-close="false" 导致鼠标用户找不到关闭入口；弹窗没有焦点 trap，Tab 会跑到背景。修复：恢复右上角关闭按钮（糖果风加大版）、role="dialog" + aria-modal + 焦点圈禁；移动端增加双指缩放（touch 事件）。
