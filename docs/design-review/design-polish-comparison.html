🍡 糖果图库 · 4 处细节优化对比

基于昨天代码落地后的 UI 现状，把「还可以更好」的 4 个小点做成改前改后对照。

1. 上传区 drag-over 反馈

中优先级

改前：用户拖文件进来时，上传区没有任何视觉变化；改后：虚线变实线、背景变薄荷绿、轻微放大。

😢 改前：拖入无反馈
☁️ 把图片或视频拖到这里
支持 jpg / png / gif / webp / mp4
😊 改后：拖入高亮
☁️ 把图片或视频拖到这里
支持 jpg / png / gif / webp / mp4
💡 实现：给 el-upload 的 drag 区域加 .drop-zone.is-dragover 样式（border-style:solid; background:var(--cartoon-mint); transform:scale(1.02)）。

2. 编辑分类时色点加 aria-label

低优先级

改前：编辑模式下颜色选择器里的色点没有标签，屏幕阅读器用户不知道当前选的是哪个；改后：每个色点都带 `aria-label="颜色 柠檬黄（对比度 4.9:1）"`。

😢 改前：编辑色点无描述

读屏器只会播报「按钮 已选中」，不知道颜色。

😊 改后：每个色点可读

读屏器会播报「颜色 柠檬黄，对比度 4.9 比 1，已选中」。

3. 移动端顶部导航防换行

中优先级

改前：375px 下 header-inner 用 flex 两端对齐，用户区会被挤到第二行；改后：用 grid 三列布局（Logo | 导航 | 用户），必要时导航换行但整体不塌。

😢 改前：用户区被挤下第二行

😊 改后：grid 三列，结构更稳

💡 更激进的方案：小屏把用户区收进头像下拉菜单，导航用 icon-only。

4. 页面术语统一

低优先级

改前：Logo、标题、空态文案人称/风格不统一；改后：标题更利落，空态保留可爱但减少无意义拟声词。

😢 改前：语气词多、称呼杂

画廊页标题：我的糖果图库

上传页标题：把图片传上来吧～

空态文案：画廊还是空的～去上传第一张图吧！

😊 改后：简洁一致

画廊页标题：画廊

上传页标题：上传图片

空态文案：还没有图片，去上传第一张吧 🐰

💡 也可以保留品牌个性，只要定一个「标题 = 功能名」的规则即可。
